# 灵犀（LingX）

Windows 桌面效率工具：常驻托盘的**剪贴板历史**、**收藏整理**、**本地加密密码本**、**消息中枢**与**任务追踪**，秒开、本地优先。

> 当前版本：**v1.0.0（已打包，待安装验收）**　｜　最后对外发布：v0.4.0　｜　平台：Windows 10/11 x64

## 功能

| 模块 | 说明 |
|---|---|
| 剪贴板 | 监听系统剪贴板，历史按日期分组；文本/图片/文件；截图自动入库 |
| 收藏整理 | 目录制收藏，一条内容可归入多个目录；支持复制、编辑、删除 |
| 密码本 | 本地加密保险库（AES-256-GCM + Argon2id），主密码解锁；闲置自动锁定；可导出加密备份、跨机打开 |
| 消息中心 | 本地 Webhook（127.0.0.1:8457）接收任意 JSON / 表单编码，或定时轮询外部 API；字段自动整理；系统通知 + 桌宠气泡 + 未读角标 |
| 任务追踪 | 自定义状态、优先级、来源、期望完成时间；状态变更与进度时间线；消息可一键转任务 |
| 桌宠 | 可选桌面宠物（默认关闭），消息气泡与点击/拖拽特效 |
| 设置 | 全局热键、开机自启（默认关闭）、通知开关、剪贴板保留天数、数据目录等 |

## 技术栈

Electron 33 · electron-vite 2 · Vue 3 · TypeScript 5 · better-sqlite3 · electron-builder（NSIS x64）

## 开发

要求：Node.js 20+、npm。（本项目在 Node 24 下开发）

```bash
npm install
npm run dev        # 开发模式（electron-vite dev）
npm run typecheck  # 类型检查（node + web）
npm run build      # 构建产物到 out/
npm run build:win  # 构建 + 打包 NSIS 安装包到 release/
```

开发版与打包版使用独立的 userData：开发版 `%APPDATA%\desktop-pet-dev`，打包版 `%APPDATA%\desktop-pet`。

## 数据与隐私

本软件**默认完全本地运行，不上传云端**。数据位置：

| 数据 | 位置 |
|---|---|
| 剪贴板数据库 + 图片 | `%APPDATA%\clipboard-plus\` |
| 应用配置 / 连接器 / 保险库设置 / 日志 | `%APPDATA%\desktop-pet\` |
| 密码本保险库 | 默认在 userData，可自定义路径；文件整体加密 |

设置页提供"数据与备份"，可一键打开上述目录。备份时请先退出应用，再复制对应目录与密码本 `.pvlt` 文件。

## 已知限制

- **安装包未做代码签名**：首次安装 Windows 可能提示"未知发布者"，点"更多信息 → 仍要运行"即可。
- 无自动更新，需手动安装新版本。
- 框选截图目前仅支持主显示器。
- 从 v0.4.0 升级到 v1.0.0 的平滑性未做完整回归，升级前建议先备份数据。
- 剪贴板数据库与旧独立版 ClipboardPlus 共用，建议只保留一个常驻进程。
