# MCP 服务端（B）— 任务追踪 / 消息给 AI 用

> 状态：草案（待你补充「待确认」部分）
> 定位：灵犀作为 **MCP 服务端**，把任务、消息暴露给 AI 助手（Claude Desktop / Cursor / 支持 MCP 的客户端）。
> 关联代码：`src/main/storage/taskRepo.ts`、`src/main/storage/*`、`src/main/ipc/index.ts`

## 1. 目标

- 让 AI 助手直接读灵犀里的任务/消息，用来做"需求 → 调研 → 排期"，减少你在工具之间来回切换。
- 不依赖灵犀内置大模型：AI 用用户自己的客户端，灵犀只负责递数据。
- 默认只读，写操作需要确认。

## 2. 工具清单（草案）

| 工具 | 权限 | 说明 |
|---|---|---|
| `list_tasks` | 读 | 按状态/优先级/关键词列任务 |
| `get_task` | 读 | 单条任务详情 + 进度时间线 |
| `list_messages` | 读 | 消息中心列表（未读/来源过滤） |
| `get_message` | 读 | 单条消息（含整理后的字段） |
| `create_task` | 写 | 从需求/消息建任务（需确认） |
| `add_task_log` | 写 | 追加进度备注（需确认） |
| `set_task_status` | 写 | 改任务状态（需确认） |
| `get_today_summary` | 读 | 今日需求数/未读/待办汇总 |

**默认不暴露**：密码本、剪贴板、设置里的密钥。

## 3. 传输方式

- **stdio（优先）**：灵犀以 `--mcp-server` 参数启动一个子进程，AI 客户端在配置里调用它；不占端口，最安全。
- **HTTP（可选）**：仅监听 `127.0.0.1`，带 Token，适合只支持 URL 的客户端。
- 设置页提供「复制 MCP 配置」按钮，一键生成客户端配置片段。

## 4. 安全策略

- 默认只读；写工具（建任务/改状态/加备注）弹窗确认后再执行。
- 密码本永不暴露；剪贴板默认关闭（后续可加开关）。
- 所有工具调用写日志（可查"AI 什么时候读了什么"）。
- HTTP 模式：仅本机 + Token + 设置里可随时关闭。

## 5. 隐私提醒（需写进设置页）

- AI 客户端在云端时（Claude/DeepSeek 等），消息里的客户姓名/手机号会离开本机；用本地模型则不会。
- 建议提供"字段脱敏"选项：手机号中间四位打码。
