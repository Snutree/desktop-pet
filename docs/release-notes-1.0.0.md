# 灵犀 v1.0.0 发布说明

## 安装包

- 文件：`LingX-Setup-1.0.0.exe`（NSIS x64，约 85.7 MB）
- SHA256：`64366F41DC95E39EF4F98E9D760843CF9F61F9D63B0CF6C890BB48C6DBB10F43`
- 系统：Windows 10 / 11 x64
- 安装：双击安装包 → 选择目录（默认按用户安装，无需管理员）→ 完成

> 安装包未做代码签名。若 Windows 提示"Windows 已保护你的电脑 / 未知发布者"，点击"更多信息 → 仍要运行"即可。

## 本版亮点

- 新增**任务追踪**与消息转任务
- 剪贴板图片显示修复；密码本"上锁后无法解锁"修复
- 密码本换机引导（新建 / 打开已有库 / 从备份恢复）
- Windows 系统通知（可开关、可聚合、点击直达消息中心）
- 任意 JSON 消息接入：Webhook 或轮询均可，字段自动整理
- 日志落盘、启动健壮性改进、开发版/打包版数据隔离

## 升级说明

- 从 0.4.0 升级：**请先备份数据**（见下）；本版未做完整的 0.4.0→1.0.0 升级回归，不保证平滑升级。
- 升级后请检查「API 配置」中的数据源是否仍然有效（旧线索接口已废弃），无效的请删除或停用。
- 旧版 `vault-settings.json` 若指向其他位置的`.pvlt`，升级后可能仍可用；如提示找不到库，用"打开已有库"重新选择。

## 数据位置（备份用）

| 数据 | 位置 |
|---|---|
| 剪贴板数据库 + 图片 | `%APPDATA%\clipboard-plus\` |
| 应用配置 / 连接器 / 保险库设置 / 日志 | `%APPDATA%\desktop-pet\` |
| 密码本保险库 | 默认在 userData；可在设置中查看实际路径 |

备份步骤：**退出灵犀** → 复制以上目录与 `.pvlt` 文件 → 恢复时放回原位置。
