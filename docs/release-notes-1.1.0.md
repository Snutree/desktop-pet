# 灵犀 v1.1.0 发布说明

> 发布日期：2026-11-08
> 平台：Windows 10 / 11 x64
> 安装包：`LingX-Setup-1.1.0.exe`（NSIS，未代码签名）
> SHA256：`73401973898588D888006B6D69FDAA725548EFD4C3DB81006E512C7D9DE7F404`

## 本次更新

### 新增：启动中心

把常用程序/启动脚本集中管理，点一下就能运行：

- 支持 `.exe` / `.bat` / `.cmd`；
- 选择文件后自动用文件所在目录作为工作目录，点击启动等同于在文件夹里双击（bat/cmd 会显示控制台窗口）；
- 左侧分组、右侧启动项；默认分组不可改名，其他分组可新建/改名/删除；
- 标签、按标签筛选、组内拖拽排序；
- 每行右侧三个按钮：绿色「启动」、黄色「编辑」、红色「删除」；
- 可勾选「默认以管理员身份启动」，启动时触发 Windows UAC；
- 自动提取程序图标。

### 剪贴板收藏

- 目录支持重命名（默认目录也可改名，不可删除）；
- 目录内收藏支持拖拽排序，每个目录独立顺序；
- 修复误删：移出最后一个目录时弹窗选择「移动到其他目录（可多选）/ 不移动直接删除 / 取消」；如果还在其他目录，则直接移出，不弹窗、不删除。

### 密码本

- 新增/编辑条目时，分类改为下拉选择已有分类，也可新建；
- 分类支持重命名（批量更新）；
- 分类支持删除，删除前提示，条目迁移到「未分类」。

### 桌宠右键菜单

新增「打开控制板 · 任务追踪」「打开控制板 · 启动中心」。

## 安装 / 升级

1. 运行 `LingX-Setup-1.1.0.exe`，按向导安装（默认当前用户，无需管理员）。
2. 从 v1.0.0 升级前，建议先备份：
   - `%APPDATA%\clipboard-plus`（剪贴板数据库与图片）
   - `%APPDATA%\desktop-pet`（配置、日志等）
   - 密码本 `.pvlt` 文件（若自定义过路径，复制对应文件）
   - 备份前先退出灵犀，避免 WAL 未落盘。
3. 数据库会自动从 v5 迁移到 v6，保险库格式不变。
4. 安装包未做代码签名：SmartScreen 可能提示"未知发布者"，点「更多信息 → 仍要运行」。

### 如果 Windows 提示"应用控制策略阻止了此文件"

这是 **Smart App Control（智能应用控制）** 在拦截未签名程序，不是安装包损坏。可在
「Windows 安全中心 → 应用和浏览器控制 → 智能应用控制」查看状态；关闭 SAC 后即可安装（关闭操作可能不可逆，请谨慎），或换一台未开启 SAC 的电脑安装。彻底解决需要代码签名证书。

## 已知限制

- 启动中心目前只支持 `.exe` / `.bat` / `.cmd`，暂不支持 `.lnk`、网址、文件夹、启动参数、隐藏控制台。
- 管理员启动依赖 Windows UAC；无管理员权限的账户会失败。
- 删除启动项/分组不会删除磁盘上的原文件。
- 安装包未签名；无自动更新，需手动安装新版本。
- 从 v0.4.0 升级的平滑性未做完整回归。
