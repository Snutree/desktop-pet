# 灵犀 v1.1.0 更新说明

> 发布日期：2026-11-08
> 适用版本：v1.0.0 → v1.1.0
> 平台：Windows 10 / 11 x64
> 安装包：`LingX-Setup-1.1.0.exe`
> SHA256：`73401973898588D888006B6D69FDAA725548EFD4C3DB81006E512C7D9DE7F404`

这次更新加入了大家等很久的**启动中心**，并把剪贴板、密码本的"分组/分类"体验统一了一轮。

---

## 一、新增：启动中心

你部署的开源项目、常用脚本，不用再每次翻文件夹了。

- 支持 `.exe` / `.bat` / `.cmd` 三种启动文件。
- 添加时选择文件，灵犀会自动把**文件所在目录**作为工作目录——点击启动的效果，和你在文件夹里双击它完全一致。
- `.bat` / `.cmd` 会正常弹出命令行窗口，不隐藏、不抢输出。
- 左侧分组、右侧启动项：
  - 默认分组 + 自定义分组，可新建、重命名、删除；
  - **默认分组不可重命名**，其他分组可以重命名；
  - 分组名称不允许重复；
  - 删除分组会先确认，并一并删除组内启动项（**不会删除磁盘上的原文件**）。
- 标签：一条启动项可以加多个标签，方便按项目/用途筛选。
- 排序：组内可以直接拖拽调整顺序。
- 每行最右侧是三个按钮：
  - 绿色「启动」
  - 黄色「编辑」
  - 红色「删除」（删除前会确认）
- 可勾选「默认以管理员身份启动」，以后点启动就按管理员方式运行（会弹 Windows UAC）。不再需要每次从下拉菜单里选择管理员启动。
- 同一个文件可以添加多次，放进不同分组。
- 启动成功不弹提示（命令行本身有输出）；失败会在行内和提示条给出原因。
- 桌宠右键菜单新增「打开控制板 · 任务追踪」「打开控制板 · 启动中心」，可直接跳到对应页面。

### 使用步骤

1. 打开控制板 → 左侧「工作台」→「⚡ 启动中心」。
2. 右上角「＋ 添加启动项」→ 选择 `.exe` / `.bat` / `.cmd` 文件。
3. 填名称、选分组（可新建）、加标签，按需勾选"默认以管理员身份启动"。
4. 保存后点「启动」即可。

## 二、剪贴板收藏改进

- **目录可以改名了**：左侧目录名右侧「✎」，点一下就能改（默认目录也能改名，只是不能删除）。
- **目录内拖拽排序**：收藏条目可以在当前目录里拖动调整顺序，每个目录的顺序互相独立。
- **修复"移出目录误删收藏"**：
  - 以前从默认目录点「移出目录」，如果这条收藏只属于这一个目录，会直接把收藏删掉；
  - 现在会弹窗，让你选择：
    1. 移动到其他目录（可多选）
    2. 不移动、直接删除这条收藏
    3. 取消
  - 如果这条收藏还在其他目录里，则直接从当前目录移出，不会弹窗、也不会删除。

## 三、密码本分类改进

- 新增/编辑密码条目时，分类改成**下拉选择已有分类**，也可以直接新建分类，不用每次手打。
- 分类支持**重命名**：重命名后，该分类下所有条目一起更新。
- 分类支持**删除**：删除前会提示"该分类下的密码将移动到「未分类」"，确认后批量迁移。
- 「未分类」是默认分类，不可删除，但可以改名。

---

## 四、数据与升级

- 数据库自动升级到 `schema_version = 6`，新增启动中心数据表，并为收藏目录增加排序字段；旧数据会自动迁移，无需手动操作。
- **升级前建议备份**：
  - `%APPDATA%\clipboard-plus`（剪贴板数据库与图片）
  - `%APPDATA%\desktop-pet`（配置、日志等）
  - 密码本 `.pvlt` 文件（默认在 userData，若自定义了路径请复制对应文件）
  - 备份前请先退出灵犀（避免 WAL 未落盘）。
- 保险库格式未变，v1.0.0 的密码本可以直接打开。

## 五、已知限制

- 启动中心目前只支持 `.exe` / `.bat` / `.cmd`；暂不支持快捷方式（.lnk）、网址、文件夹、自定义命令、启动参数。
- "以管理员身份启动"会触发 Windows UAC；如果系统账户没有管理员权限，会启动失败。
- 删除启动项/分组只删除灵犀里的记录，不会删除磁盘上的原文件。
- 启动中心暂未做全局热键/快速启动面板（后续版本考虑）。
- 安装包仍未做代码签名，SmartScreen 可能提示"未知发布者"。
- 如果系统开启了 **Smart App Control（智能应用控制）**，未签名安装包会被直接拦截（提示"应用控制策略阻止了此文件"）。这不是安装包损坏，需要关闭 SAC 或换未开启 SAC 的电脑安装。

## 六、反馈

遇到问题请带上 `%APPDATA%\desktop-pet\logs\main.log` 和复现步骤。
